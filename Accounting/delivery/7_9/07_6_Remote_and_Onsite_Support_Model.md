# Section 7.6 Remote and On-Site Support Model

## 1. Objective
Provide an integrated remote and on-site support approach to address both routine and critical operational needs.

## 2. Remote Support Capabilities
- Remote diagnostics and log analysis
- Configuration fixes and controlled updates
- Live incident triage sessions
- Performance tuning and monitoring checks

## 3. On-Site Support Triggers
- Critical production failures requiring physical intervention
- Infrastructure and network incident dependencies
- Major release cutovers or high-risk changes
- Security incident requiring controlled local response

## 4. Dispatch Model
| Incident Type | Mode | Dispatch Target |
|---|---|---|
| Critical outage | Remote + On-site | Immediate remote, on-site per contract window |
| High-impact issue | Remote first, on-site if needed | Same business day |
| Medium/Low issue | Remote | Scheduled |

## 5. Remote Access and Security Controls
- Approved access channels only
- Named engineer access with audit logging
- Least privilege and time-bounded access
- Session recording where required

## 6. On-Site Engagement Checklist
- Incident summary and objective
- Required access and approvals
- Safety and compliance constraints
- Exit report with actions taken
