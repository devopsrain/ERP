እገዛ / Help — how to connect EBMS to Telegram

Telegram
Create the bot with @BotFather
  1. In Telegram open @BotFather and send /newbot.
  2. Choose a display name (e.g. EBMS Assistant) and a username ending in bot (e.g. ebms_devopsrain_bot).
  3. BotFather replies with the HTTP API token — this becomes TELEGRAM_BOT_TOKEN. Keep it secret.
  4. Optional: /setcommands and paste the command list below so Telegram shows a menu.
  5. Optional for groups: /setprivacy → Disable so the bot sees /commands in group chats.

Reachability — Tailscale Funnel / HTTPS

Telegram delivers updates by calling your server, so the webhook URL must be reachable from the public internet over HTTPS with a valid certificate (ports 443, 80, 88 or 8443). The EBMS server is not internet-facing; it is published through Tailscale Funnel:

sudo tailscale funnel --bg 443        # or: tailscale funnel --bg --https=443 http://127.0.0.1:8080
tailscale funnel status

Point TELEGRAM_PUBLIC_BASE_URL at the URL Funnel reports (or at https://ebms.devopsrain.com if that name resolves to the Funnel endpoint). Only /telegram/webhook needs to be public — every other /telegram/ page requires a staff login.

Register the webhook

On the Telegram dashboard an admin clicks Set webhook. EBMS calls setWebhook with the URL above and the secret token. The dashboard then shows what Telegram has registered, pending updates and the last delivery error.

Manual check: curl https://api.telegram.org/bot<TOKEN>/getWebhookInfo. Remove webhook stops delivery (useful before switching environments).

Link users and subscribe
  1. Each user opens Telegram → Link, generates a 6-character code (valid 15 minutes, single use).
  2. In Telegram: /start, then /link CODE. The chat is bound to that EBMS user and their current company; unknown chats only get a polite "not linked" reply.
  3. Manage topics on Subscriptions or with /subscribe <topic>.

For developers — sending from other modules
from telegram_bot import notify_user, notify_topic

notify_user("admin", "<b>Payroll</b> for July posted.")          # every chat linked to that user
notify_topic("default", "approvals", "New PO waiting for approval")  # every chat in the company subscribed to the topic

Both enqueue into telegram_outbox; the scheduler flushes it every minute with retry (5 attempts, exponential backoff). Text is HTML — escape user data with telegram_bot.esc(). The daily digest runs at 07:30 server time. Schema: telegram_links, telegram_link_codes, telegram_subscriptions, telegram_outbox, telegram_updates_log (created automatically at startup).
