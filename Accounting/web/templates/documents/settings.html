How to connect
  1. In Nextcloud (http://192.168.68.121:8081) create a dedicated user ebms.
  2. Log in as that user → Settings → Security → Devices & sessions → create an App password named "EBMS".
  3. On the server add to /opt/ebms/Accounting/.env: 
    NEXTCLOUD_URL=http://host.docker.internal:8081
NEXTCLOUD_USER=ebms
NEXTCLOUD_APP_PASSWORD=xxxxx-xxxxx-xxxxx-xxxxx-xxxxx
NEXTCLOUD_ROOT=EBMS
    (or http://192.168.68.121:8081 if host.docker.internal does not resolve)
  4. cd /opt/ebms/Accounting && docker compose up -d web api
  5. Reload this page and press Test connection.

Full guide: nextcloud/SETUP.md → "Connecting EBMS to Nextcloud".
