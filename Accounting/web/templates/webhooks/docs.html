1. Authentication (API keys)

Create a key under API Keys. Keys are scoped to the company that created them and look like ebms_…. Send one of these headers with every request:

X-API-Key: ebms_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
# or
Authorization: Bearer ebms_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Responses: 401 when the key is missing, unknown, revoked or expired; 403 when the key lacks a required scope.

3. Payload format

Every delivery is an HTTP POST with a JSON body and these headers:

POST https://your-server.example/ebms
Content-Type: application/json
User-Agent: EBMS-Webhooks/1.0
X-EBMS-Event: invoice.created
X-EBMS-Delivery-Id: 5b0e7d5e-…            # unique per delivery, stable across retries
X-EBMS-Signature: t=1757600000,v1=8f3a…    # see section 4

{% raw %}{"id":"5b0e7d5e-…","event":"invoice.created","company_id":"acme",
 "created_at":"2026-09-11T10:15:00","data":{"invoice_id":"INV-0042","total":1500.0,...}}{% endraw %}

Respond with any 2xx within 10 seconds to acknowledge. Anything else (or a timeout) is treated as a failure and retried.

4. Verifying signatures

The signature protects against forged calls. t is the Unix timestamp at send time; v1 is HMAC-SHA256(secret, t + "." + raw_body) in hex. Compute it over the raw request bytes (do not re-serialise the JSON), compare in constant time and reject timestamps older than ~5 minutes.

{% raw %}import hmac, hashlib, time
from flask import Flask, request, abort

SECRET = "whsec_..."          # from the endpoint's edit page
app = Flask(__name__)

def verify(secret: str, raw_body: bytes, header: str, tolerance: int = 300) -> bool:
    parts = dict(p.split("=", 1) for p in header.split(",") if "=" in p)
    t, v1 = parts.get("t"), parts.get("v1")
    if not t or not v1 or abs(time.time() - int(t)) > tolerance:
        return False
    expected = hmac.new(secret.encode(), f"{t}.".encode() + raw_body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, v1)

def ebms_webhook():

        abort(401)

{% raw %}const crypto = require("crypto");
const express = require("express");

const SECRET = "whsec_...";   // from the endpoint's edit page
const app = express();

function verify(secret, rawBody, header, tolerance = 300) {
  const parts = Object.fromEntries(header.split(",").map(p => p.split("=")));
  const t = parseInt(parts.t, 10), v1 = parts.v1 || "";
  if (!t || Math.abs(Date.now() / 1000 - t) > tolerance) return false;
  const expected = crypto.createHmac("sha256", secret)
    .update(`${t}.`).update(rawBody).digest("hex");
  return expected.length === v1.length &&
    crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(v1));
}

// keep the raw bytes — express.json() would re-serialise the body
app.post("/ebms", express.raw({ type: "*/*" }), (req, res) => {
  if (!verify(SECRET, req.body, req.get("X-EBMS-Signature") || "")) return res.sendStatus(401);
  const event = JSON.parse(req.body.toString("utf8"));
  console.log(event.event, event.data);
  res.sendStatus(204);
});
app.listen(3000);{% endraw %}
5. Retries & idempotency

A delivery that does not get a 2xx is retried with exponential backoff — roughly 1 min, 4 min, 16 min, 1 h, 4 h — up to {{ max_attempts }} attempts, after which it is marked dead and can be re-queued manually from the deliveries page.

Retries carry the same X-EBMS-Delivery-Id; store processed ids and treat repeats as no-ops so a slow acknowledgement never causes double processing. Delivery history is kept for 30 days.

6. Inbound callbacks

Third parties may POST to {{ base_url }}/webhooks/inbound/<source> (any content type, no login). EBMS records the raw body and headers and returns 202 Accepted. Configure a secret per source on the overview page; the caller's X-Signature header is then verified as either t=…,v1=…, sha256=<hex> or a bare hex HMAC-SHA256 of the body.

Use ?company_id=… or X-EBMS-Company when the same source serves several companies.
